Google ADK 三大确定性工作流原语拓扑对比

SequentialAgent（顺序流水）、ParallelAgent（并发扇出）与 LoopAgent（反馈自愈）拓扑特征横向对比

Sequential 线性管道

  • • 步骤不可跳跃，按配置顺序依序单向推流
  • • output_key 结构化写入与提取，杜绝长链上下文雪崩
  • • 适用场景：代码重构流水线、数据 ETL 清洗与转换

Parallel 并发极致

  • • 无依赖子任务同时分发，Join 屏障统一汇聚
  • • 耗时由最长单步决定，但需注意 API 速率限制 (RPM/TPM)
  • • 适用场景：多视角安全与性能交叉审计、多信源检索

Loop 质检自愈

  • • Generator ⇄ Critic 闭环迭代，直至规则定量达标
  • • 强制配置 max_iterations（如3次）防止死循环失控
  • • 子 Agent 调用工具设 actions.escalate=True 提前破环放行
