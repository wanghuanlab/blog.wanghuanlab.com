Google ADK 概念分层架构体系 (Pattern vs Workflow)

顶层多智能体协作模式、确定性代码工作流与底层认知执行单元的架构解耦

顶层模式解耦

  • • Supervisor、Handoff 等是架构设计模式，非内置同名类
  • • 通过组合 LlmAgent、工作流容器与工具接口搭建
  • • 根据业务需要自由选择集中指挥或对等转交

确定性工作流

  • • Sequential、Parallel、Loop 属于代码调度的工作流容器
  • • 容器按代码调度；子任务仍需超时和预算约束
  • • 共享 Session State 与 output_key 实现数据透明接力

控制权保障核心

  • • 经典 transfer 会转接；新协作模式需按版本区分
  • • AgentTool 将子 Agent 作为工具调用并返回结果
  • • 新版 Python 可使用 single_turn 子 Agent 自动返回
