企业级多智能体协同推荐架构 (Enterprise Composite Topology)

Supervisor 集中调度、三大确定性工作流管道与 Temporal 分布式持久化底座的深度融合

主控权永不脱缰

  • • Supervisor 通过 AgentTool 调用专员智能体
  • • 子 Agent 在沙箱隔离环境中运行完单次任务即返回
  • • 主控始终保有会话主导权，杜绝 Handoff 模式下的迷航

动静结合的高弹性

  • • 模糊非确定性意图交给 LLM Supervisor 规划
  • • 严谨业务依赖交给 Sequential 固化前后顺序
  • • 独立耗时任务交给 Parallel 并发压缩延迟

生产级长任务兜底

  • • 外层统一由 Temporal 状态机引擎保活
  • • 服务重启或网络中断时任务从最近检查点无缝恢复
  • • 支持数小时甚至数天跨周期的人工审批挂起
