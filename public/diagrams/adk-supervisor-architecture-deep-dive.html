Google ADK · 企业级 Supervisor 模式架构深度拆解

主控管控协同 · 业务 MCP 权责下沉 · 进程内 AgentTool / 分布式 A2A 协议治理体系

主控专注协调，严禁越俎代庖

  • • 指挥官定位：主控 Agent（Supervisor）负责意图识别、全局任务 DAG 规划与终态验收，绝不直接挂载业务写操作工具。
  • • 注意力保护：主控若挂载大量业务 MCP，大量 Tool Schema 会瞬间挤占 Context Window，造成注意力稀释（Attention Dilution）。

业务 MCP 工具必须权责下沉

  • • 权限最小化原则（PoLP）：Git/CI 挂载给研发专员，数据库与数据湖挂载给分析专员，代码扫描挂载给审查专员。
  • • 纵深防御防越狱：即使主控遭遇用户 Prompt Injection 注入攻击，由于主控本身没有写库和发布工具，无法直接造成破坏。

进程内 AgentTool 与分布式 A2A

  • • 本地单进程：通过 Google ADK AgentTool 将专员包装为内存高阶函数，零网络损耗，控制权常驻主控。
  • • 分布式微服务：跨网络、跨容器调度通过 A2A Protocol（基于 gRPC/JSON-RPC 的 Task Envelope 契约）解耦伸缩。
