主控 Agent 的控制权不灭机制

  • • AgentTool 沙箱封装：拒绝使用 subAgents（会触发 Transfer 导致控制权彻底移交），采用 AgentTool 将子智能体包装为标准高阶工具，主控始终保有唯一会话主导权。
  • • ReAct 动态自愈闭环：Supervisor 根据专员返回的结构化打分和建议，可自主决定是否重新下发任务修正，实现动态非线性规划。

A2A 与 MCP 通信协议分工

  • • A2A 智能体间协议：专注于智能体之间的认知上下文交互、结构化 DTO 契约输入输出、分级授权与事件通知。
  • • MCP 外部世界协议：统一标准化外接企业数据库、Git 代码仓库、搜索引擎与内部微服务，实现无缝插件式热插拔。

支撑服务筑牢企业级底座

  • • Temporal 状态持久化：托底长达数十小时的长周期任务，提供任意节点宕机重放（Replay）自愈与断点恢复能力。
  • • 安全围栏与 HITL 人机协同：高敏感外设操作（如生产库写操作、部署上线）自动阻塞并抛出工单，待人工核准后恢复执行。
